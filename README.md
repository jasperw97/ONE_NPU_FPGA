# ONE NPU FPGA Deployment
This repo includes the files (NPU RTL, Vivado block design of validation platform, and scripts to run testbenches) needed to deploy the ONE NPU on an AMD Xilinx vu13p FPGA and perform functional validation.

## /new_npu
RTL source code and behavioral testbench of the NPU.

## /npu_testing_system
AXI packaged NPU IP and Vivado project of the validation platform. NPU is parametrizable, currently the 8-lane version (npu_8x8) successfully runs, but the 32-lane version (npu_32) fails timing after implementation.

## /npu_testing_system/tb_scripts
Scripts needed to write data to DRAM through JTAG-to-AXI-Master, read back results, and compare results. Also includes test data and golden results generated by the behavioral testbench in /new_npu.

## /resources
Includes the csv file for the DDR4 used in NYCU CAS Lab. Make sure to configure the file by clicking on the DDR4 MIG block in the Vivado block design and point it to the correct file.
